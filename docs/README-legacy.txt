================================================================
  DISPATCH LIVE  —  Command Deck  (מסך מצב)
================================================================

מסך מצב אחד שמאחד הכל:
  - 7 ערוצי טלוויזיה ישראליים בשידור חי
  - צבע אדום (צופר) — אזעקות בזמן אמת + היסטוריה + מפת חום
  - חדשות מתפרצות מ-19 מקורות (ישראל + עולם)
  - פס דובר צה"ל (3 הודעות אחרונות מהערוץ הרשמי)

הכל על מסך אחד, עם פריסה גמישה — אתה בוחר איזה בלוק גדול.


----------------------------------------------------------------
  תלויות  (Dependencies)
----------------------------------------------------------------

** אין תלויות חיצוניות. ** לא צריך pip install / npm install.
השרת משתמש רק בספריות הסטנדרטיות של Python / Node.

הדבר היחיד שצריך מותקן (אחד מהם מספיק, שניהם חינם):
   - Python 3.7+   https://www.python.org/downloads/
   - או Node.js 18+  https://nodejs.org
ובנוסף: דפדפן מודרני (Edge / Chrome / Safari / Firefox).


----------------------------------------------------------------
  תאימות מערכות הפעלה
----------------------------------------------------------------

  Windows  — ✅ מלא. הפעל  Start-Dispatch-LIVE.bat
  Mac      — ✅ הפעל  Start-Dispatch.command  (לחיצה כפולה)
  Linux    — ✅ הפעל  ./Start-Dispatch.sh  מהטרמינל
  טלפון (אנדרואיד / iPhone) — ✅ צפייה דרך ה-Wi-Fi
       המחשב מריץ, הטלפון צופה. ראה  ANDROID-README.txt
       (הרץ Start-Dispatch-NETWORK.bat במקום הרגיל)

על Mac: בפעם הראשונה ייתכן ש-macOS יחסום קובץ לא-חתום.
  לחץ ימני על Start-Dispatch.command -> Open -> Open.
  (או הרץ מהטרמינל:  ./Start-Dispatch.command)


----------------------------------------------------------------
  הפעלה  (Windows)
----------------------------------------------------------------

1. צריך Python או Node.js מותקן (ראה "תלויות" למעלה).

2. חלץ את התיקייה לאן שתרצה, למשל  C:\Dispatch-LIVE\

3. הפעל בלחיצה כפולה:  Start-Dispatch-LIVE.bat
   - חלון שחור ייפתח (השרת) והדפדפן ייפתח אוטומטית במסך מלא
   - ** סגירת חלון הדפדפן סוגרת גם את השרת אוטומטית **
     (התנהגות של אפליקציה אחת - אין צורך לסגור כלום ידנית)
   - לעצירה ידנית:  Stop-Dispatch.bat
   - לבדיקה מה רץ:  Check-Running.bat
   - להשארת השרת דולק גם אחרי סגירת החלון:  set NOAUTOCLOSE=1


----------------------------------------------------------------
  הפעלה  (Mac / Linux)
----------------------------------------------------------------

Mac:   לחיצה כפולה על  Start-Dispatch.command
Linux: בטרמינל, מתוך התיקייה:   ./Start-Dispatch.sh

השרת יפתח את הדפדפן אוטומטית. לעצירה: Ctrl+C בחלון הטרמינל.


----------------------------------------------------------------
  למה צריך שרת מקומי?
----------------------------------------------------------------

ה-API של פיקוד העורף (oref.org.il) חוסם גישה ישירה מהדפדפן (CORS)
וגם חוסם IP לא-ישראלי. השרת המקומי שרץ אצלך:
  - פונה ל-API של צופר עם הכותרות הנכונות
  - מ-IP ישראלי שלך (לכן זה עובד)
  - מעביר את התשובה לדפדפן בלי בעיות CORS

זה גם מה שמאפשר לכל מקורות החדשות להיטען בלי הגבלות.


----------------------------------------------------------------
  שימוש
----------------------------------------------------------------

תצוגה (סרגל עליון):
  - מאוזן   = שלושת הבלוקים בגודל דומה
  - טלוויזיה = הטלוויזיה גדולה, חדשות+צופר ברצועה
  - חדשות   = החדשות גדולות
  - צופר    = ההתרעות גדולות

טלוויזיה:
  - כפתור "ערוצים" — בחר אילו מ-6 הערוצים להציג
  - כפתור הגדלה על כל ערוץ — מסך מלא לאותו ערוץ
  - הערוצים מושתקים כברירת מחדל (מדיניות דפדפן);
    לחץ על וידאו כדי לבטל השתקה

צופר:
  - כשיש אזעקה פעילה — כל המסך הופך לאדום עם רשימת הערים
  - היסטוריית השעות האחרונות מוצגת בבלוק
  - כפתור "בדיקה" — תצוגה מקדימה של ההשתלטות (לא אזעקה אמיתית)
  - כפתור הרמקול בסרגל העליון — הפעלה/כיבוי צליל אזעקה

חדשות:
  - כפתור "מקורות" — בחר אילו מקורות
  - חדשות מהדקות האחרונות מסומנות באדום (מבזק)

  הערוצים
----------------------------------------------------------------

----------------------------------------------------------------
  פתרון בעיות
----------------------------------------------------------------

- "אין אזעקות" + "לא ניתן לטעון היסטוריה":
  אתה כנראה לא מ-IP ישראלי, או ה-API חסם זמנית. מ-IP ישראלי
  זה עובד. המערכת ממשיכה לנטר וינסה שוב כל 5 שניות.

- ערוץ טלוויזיה שחור:
  הסטרים אולי לא זמין כרגע. נסה לרענן (כפתור למעלה) או
  לכבות/להדליק את הערוץ. i24 ורשת 13 תלויים בנגן שלהם.

- "This site can't be reached":
  חלון השרת השחור נסגר. הפעל שוב את ה-BAT.

- רוצה שזה יתחיל עם Windows:
  Win+R, הקלד  shell:startup  , גרור לשם קיצור דרך ל-BAT.
