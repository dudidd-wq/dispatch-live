# חדר מצב · DISPATCH LIVE

מסך שליטה ביתי בעברית: 8 ערוצי שידור חי, חדשות ממוינות, התרעות פיקוד העורף עם מפה,
מד מתיחות, רעידות אדמה, מדדים, טיסות ומפת עומסי תנועה ארצית.

רץ כולו על המחשב שלך. Python בלבד, בלי התקנת חבילות (`pip`), בלי חשבון ובלי ענן.

## הפעלה

| מערכת | פקודה |
| --- | --- |
| Windows | לחיצה כפולה על `Start-Dispatch-LIVE.bat` |
| Windows, צפייה גם מהטלפון ברשת הביתית | `Start-Dispatch-NETWORK.bat` |
| Mac / Linux | `./Start-Dispatch.sh` |
| Windows, ברקע בלי חלונות שחורים | `Start-Dispatch-BACKGROUND.bat` (הפלט נכתב לתיקיית `logs`) |
| Windows, הפעלה אוטומטית בכניסה למחשב | `Install-Autostart.bat` פעם אחת (רישום למשתמש הנוכחי, בלי הרשאות מנהל); הסרה ב-`Uninstall-Autostart.bat` |
| עצירה | `Stop-Dispatch.bat` (או סגירת חלון המסך) |

נדרש Python 3.9 ומעלה. המסך נפתח בכתובת `http://localhost:3100`.

## הגדרות

גלגל השיניים בכותרת פותח את מסך ההגדרות: יישוב הבית, ערוצים (כולל הוספת ערוץ), מקורות חדשות
(כולל הוספת RSS), ספי התנועה והתקציב, פס המדדים וגודל הגופן.

ההגדרות נשמרות בקובץ `config.local.json` בתיקייה הזו, והן חלות על כל דפדפן ומכשיר שפותח את המסך.
שלוש שכבות, המאוחרת גוברת:

1. ברירות המחדל שבקוד, זהות להתנהגות לפני שהיה קובץ הגדרות.
2. `config.json` — אופציונלי, משותף, אפשר להעלות לריפו.
3. `config.local.json` — של המחשב הזה בלבד, לא עולה לריפו.

שינוי הגדרות אפשרי רק מהמחשב שמריץ את המערכת (`localhost`). טלפון ברשת הביתית רואה את ההגדרות ולא יכול לשנות אותן.
תקרת הקריאות החודשית לתנועה מוגבלת ל-4,900 בכל מקרה, מתחת ל-5,000 החינמיות.

## בריאות המערכת

הנורית "מקורות" בכותרת ירוקה כשכל המקורות עונים, צהובה כשמקור משני נפל ואדומה כשמקור קריטי (פיקוד העורף) נפל.
לחיצה עליה פותחת לוח שמראה לכל מקור מתי ענה לאחרונה, זמן תגובה והשגיאה האחרונה.

בדיקה עצמית רצה כדקה וחצי אחרי ההפעלה ואז פעם ביממה: היא בודקת שכל מקור עדיין מחזיר את המבנה שהמסך יודע לקרוא.
כך שינוי באתר של מקור (כמו החלפת האתר של פיקוד העורף ב-2026) מתגלה באותו יום.

## ארכיון

כפתור הגרף בכותרת פותח את הארכיון: סיכום של 12 שעות, יממה או שבוע (התרעות, מד המתיחות, תנועה),
וגרפים של שבוע, חודש או שלושה חודשים.

הנתונים נשמרים במחשב הזה בלבד, בקובץ `data/archive.db`, עד 400 יום:
התרעות בכל רענון, מד המתיחות כל 5 דקות (כשהמסך פתוח במחשב הזה), ותנועה כל רבע שעה.
פיקוד העורף מחזיר היסטוריה של שבוע בלבד; כשהשבוע שקט, האירוע האחרון במסך מגיע מהארכיון המקומי.

## כשמקור נופל

המסך ממשיך להציג את התשובה התקינה האחרונה של המקור, עד 6 שעות, ולוח הבריאות מציין שהנתון ישן.
החריג הוא ההתרעה הפעילה מפיקוד העורף: היא לעולם לא מוצגת מנתון ישן.

## מפת התנועה (אופציונלי)

בלי מפתח המערכת עובדת, רק בלי נתוני תנועה.

1. Google Cloud Console → להפעיל **Routes API** → ליצור API key ולהגביל אותו ל-Routes API.
2. לשמור את המפתח בקובץ `google.key` בתיקייה הזו (שורה אחת, בלי רווחים).

`google.key` רשום ב-`.gitignore` ולעולם לא עולה לריפו. התקציב נעצר ב-4,500 קריאות
בחודש, מתחת ל-5,000 החינמיות. פירוט: [docs/traffic-brain.txt](docs/traffic-brain.txt).

## פיתוח

```
python -m unittest discover -s tests     # בדיקות יחידה, stdlib בלבד
node tests/check_js.js                   # ה-JavaScript שבתוך index.html מתפרש
node tests/render_test.js                # בדיקת תצוגה בדפדפן (דורש playwright)
```

אותן בדיקות רצות ב-GitHub Actions על כל push.
כשמספר הגרסה ב-`index.html` משתנה והבדיקות עוברות, נוצרים אוטומטית תג ו-Release עם קובץ ההתקנה `dispatch-live-v<גרסה>.zip` (למשל `dispatch-live-v17.11-82.zip`). בתוכו תיקייה בשם `dispatch-live-app`: מחלצים לתיקייה שמעליה (למשל `Downloads`) כדי לעדכן את הקיימת.
בכל מסירה מעדכנים את מספר הגרסה בשני מקומות ב-`index.html` (`DL_BUILD` ו-`build-tag`) ושורה ב-[CHANGELOG.md](CHANGELOG.md).

התוכנית קדימה: [docs/ROADMAP.md](docs/ROADMAP.md).
